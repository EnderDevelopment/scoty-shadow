# Scoty the Shadow

Scoty the Shadow is a unique Minecraft Bedrock Edition add-on that introduces a new entity, Scoty, a humanoid shadow with a dark black body and visible eyes. Scoty is highly durable and deals high damage to hostile monsters. He can be befriended using a flower, and when befriended, he protects the player by attacking nearby hostile mobs. The add-on includes a complete behavior pack and resource pack, with multiple eye color options for Scoty.

## Install

1. Download the Scoty.mcaddon file from the GitHub repository.
2. Open Minecraft Bedrock Edition.
3. Go to the "Add-Ons" section in the settings.
4. Click on "Add" and select the downloaded Scoty.mcaddon file.
5. Ensure both the behavior pack and resource pack are enabled.

## Use

1. Spawn Scoty using the in-game commands or by placing a spawn egg (if supported by the add-on).
2. To befriend Scoty, hold a flower and interact with him.
3. Once befriended, Scoty will protect you by attacking hostile mobs within a certain range.
4. To change Scoty's eye color, hold a flower and interact with him again (if supported by the add-on).
